# Configuration

All settings live in `.env` at the repo root. `install.sh` writes a working one; this page explains
each value. After changing any `NEXT_PUBLIC_*` value, re-run `./install.sh`: those are compiled into the
dashboard at build time.

Provider OAuth apps for integrations (GitHub, Google, Slack…) go in an optional `.env.integrations`; see
[`.env.integrations.example`](../.env.integrations.example).

## Required

| Variable | What it is | Generated by installer |
| --- | --- | --- |
| `NORIX_HTTP_PORT` | Host port nginx listens on (`80`; use `8080` behind a TLS proxy) | yes |
| `NEXT_PUBLIC_APP_URL` | Public URL people open, e.g. `https://norix.example.com` | from `NORIX_URL` |
| `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_BACKEND_URL` | Same origin as the app (nginx routes `/v1` to the gateway) | yes |
| `POSTGRES_PASSWORD` | Password of the bundled Postgres | yes |
| `DATABASE_URL` | `postgresql://postgres:<password>@postgres:5432/ai_governance` | yes |
| `REDIS_URL` | `redis://redis:6379` | yes |
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | Clerk publishable key (`pk_...`) | asked |
| `CLERK_SECRET_KEY` | Clerk secret key (`sk_...`) | asked |
| `CLERK_FRONTEND_API` | Clerk Frontend API host, used by the gateway to verify JWTs | derived from the publishable key |
| `NEXT_SERVER_ACTIONS_ENCRYPTION_KEY` | Base64 32-byte key for Next.js server actions | yes |
| `AWS_CREDENTIALS_ENCRYPTION_KEY` | Base64 32-byte AES-256-GCM key for stored credentials. **Back it up.** | yes |
| `AGENT_DISCOVERY_CRON_SECRET` | Shared secret between the schedulers and the web app | yes |
| `NANGO_ENCRYPTION_KEY` | Base64 32-byte key Nango encrypts credentials with. **Back it up.** | yes |
| `NANGO_SECRET_KEY` | UUID; the API key NORIX uses to call Nango | yes |
| `NANGO_HOST` | `http://nango-server:3003` (internal) | yes |
| `NANGO_SERVER_URL`, `NANGO_PUBLIC_SERVER_URL`, `NEXT_PUBLIC_NANGO_API_URL` | `<NEXT_PUBLIC_APP_URL>/nango-api` | yes |
| `NANGO_PUBLIC_CONNECT_URL`, `NEXT_PUBLIC_NANGO_CONNECT_URL` | `<NEXT_PUBLIC_APP_URL>/nango-connect` | yes |
| `NANGO_DASHBOARD_USERNAME`, `NANGO_DASHBOARD_PASSWORD` | Basic auth for Nango's own dashboard | yes |

## Optional

| Variable | What it enables |
| --- | --- |
| `CLERK_WEBHOOK_SECRET` | Immediate user/org sync from Clerk ([setup](self-hosting.md#clerk)) |
| `OPENAI_API_KEY`, `GEMINI_API_KEY`, `GEMINI_MODEL` | LLM-backed guards and features. Tenants can also bring their own keys (BYOK) in the UI. |
| `RADAR_ENABLED`, `RADAR_LLM_PROVIDER`, `RADAR_LLM_MODEL`, `RADAR_LLM_API_KEY`, `RADAR_INTERVAL_HOURS` | AI Radar regulatory monitoring (defaults: on, `gemini`, every 72 h; key falls back to `<PROVIDER>_API_KEY`) |
| `BRAVE_SEARCH_API_KEY` | Web search for AI Radar |
| `AGENT_DISCOVERY_INTERVAL_HOURS` | How often agent discovery runs |
| `HF_TOKEN` | Downloading gated Hugging Face models for the ONNX guards |
| `ENABLE_ONNX_MODELS`, `PRELOAD_ALL_MODELS` | Turn the ML guard models off on small machines, or preload them at start |
| `NEXT_PUBLIC_CONTROLNET_GATEWAY_URL` | Serve the gateway from a different host than the dashboard |
| `NEXT_PUBLIC_POSTHOG_KEY`, `NEXT_PUBLIC_POSTHOG_HOST` | Product analytics. Off unless set. |
| `LOG_LEVEL` | `INFO` by default |

## Installer settings

These are read by `install.sh` only, not stored in `.env`:

| Variable | Default |
| --- | --- |
| `NORIX_URL` | `http://localhost` (plus `:port` when not 80) |
| `NORIX_DIR` | `~/norix` (clone target when run via `curl`) |
| `NORIX_REPO` | `https://github.com/kentronai/Norix.git` |
