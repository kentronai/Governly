# Code of Conduct

Governly follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers, and keep criticism about the work, not
the person. Harassment, insults and personal attacks are not tolerated in issues, pull requests,
discussions or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainers through a
[private security advisory](https://github.com/kentronai/Norix/security/advisories/new) (it reaches only
maintainers). Reports are handled confidentially, and maintainers may remove content or block
participants who break this code.
